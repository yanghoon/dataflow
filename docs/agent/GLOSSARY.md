# Agent Request Portal

일반 사용자가 신청과 설정을 하는 셀프 서비스 포털. 화면, 채팅, 사용자의 AI 에이전트(MCP) 어디로 들어와도 같은 업무 규칙과 권한이 적용된다.

## Language

**작업**:
사용자나 AI가 시스템에 요청하는 업무 한 건. 조회, 설정 변경, 신청 등 모두 작업이다.
_Avoid_: 요청, 호출

**신청서**:
승인이 필요한 작업의 변경 내용을 담은 초안. 한 번 만들면 값을 고치지 않고, 수정은 새 버전으로 한다.
_Avoid_: 요청서, 드래프트

**승인**:
정해진 승인자가 신청서를 확인하고 실행을 허락하는 행위. 승인자의 종류, 조합, 순서는 비즈니스가 정한다.
_Avoid_: 결재, 컨펌

**중요 작업**:
AI는 신청서만 만들고 사람이 확인해 승인해야 실행되는 작업. 표시가 없는 작업의 기본값이다.
_Avoid_: 위험 작업

**사소 작업**:
AI가 바로 실행해도 된다고 표시한 작업. 이 표시는 작업마다 사람이 정한다.
_Avoid_: 일반 작업, 안전 작업

**감사 로그**:
작업이 일어난 사실(누가, 언제, 무엇을, 결과)을 한 건씩 추가만 하는 기록. 고치거나 지우지 않는다.
_Avoid_: 이력, 로그, 히스토리

**입구**:
사용자나 AI가 시스템에 들어오는 경로. 웹 화면, 채팅, MCP, A2A가 있다.
_Avoid_: 채널, 인터페이스

**사용자 에이전트**:
사용자를 대신해 우리 도구를 호출하는 사용자 쪽 AI. 첫 사례는 Claude Code다.
_Avoid_: 봇, 클라이언트

**알파 게이트**:
관리자 단계에서 일부 사용자에게 개방하기 전에, 지표로 통과 여부를 정하는 판단 지점.
_Avoid_: 알파 기준, 출시 조건

**활성화 지표**:
도구가 실제로 쓰이는 정도를 재는 지표(예: 주간 활성 사용자, 도구별 호출 수).
_Avoid_: 사용률, 도입률
